אתר תמיכה רגשית לנשים – ששון אלעד

הפעלה:
1. חלץ את קובץ ה-ZIP.
2. פתח את index.html בדפדפן.

לפני פרסום:
- עדכן מספר טלפון וקישור WhatsApp בקובץ index.html.
- עדכן CONTACT_EMAIL בקובץ script.js.
- הוסף פרטי הכשרה, הסמכות, ניסיון ומיקום מפגשים מדויקים.
- ודא שכל השירותים והתיאורים תואמים להכשרה, להסמכה ולדין החל.
- טופס הפנייה משתמש ב-mailto ואינו שומר מידע בשרת.

האתר סטטי, רספונסיבי, בעברית ובכיווניות RTL.
